# SentinelShield Scripts & Generators

Utility scripts and report generators for SentinelShield.

---

## 🛠️ Available Scripts

- **`generate_mentor_pdf.py`**: Generates formatted PDF mentor briefings and hackathon submission summaries.
- **`generate_mentor_pdf_v2.py`**: Extended ReportLab PDF generator including architecture diagrams, threat matrix tables, and evaluation metrics.

### Usage
```bash
python scripts/generate_mentor_pdf_v2.py
```
